## A3.1 — synthetic simulator and request-signing primitives

The initial increment adds:
- deterministic route generation from explicit synthetic coordinates and a reproducible seed;
- monotonic sequence numbers and timezone-aware timestamps;
- explicit synthetic provenance on every generated fix;
- HMAC request signing over the request timestamp and exact body bytes;
- digest-derived signing keys so the raw device credential need not be stored;
- unit tests for determinism, bounds, invalid inputs, timestamp/body tampering and malformed credentials.

These are foundational primitives only. They do not yet constitute a persistent device registry, an HTTP telemetry endpoint, a map server, or production-ready device security.
